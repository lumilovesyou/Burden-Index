# Burden Index

<sup>Because the name "Task Manager" is already taken</sup>

## About

Burden Index is a tool to help keep track of chores and tasks you need to complete. The sole goal is to keep it as simple as possible with no server backend or sign-in. Just track tasks, not passwords.
